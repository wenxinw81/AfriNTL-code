# Protocol mapping and implementation decisions

Source basis: AfriNTL_manuscript_C13_final.docx and AfriNTL_C13_Appendix.docx supplied 6 November 2026. The documents themselves remain private/local and are not uploaded.

* Section 3.2 / A1–A2: temporal source provenance (SM), offset (YD), availability (PM), target Li, held-out references, masked temporal attention. Width, head count, activation and detailed encoder choices in this reference implementation are configurable engineering choices, not claimed historical settings. Entire spatially missing observations must be filled and masked before model input; PM only handles unavailable temporal positions.
* Section 3.3 / A3: population on target grid in persons/km². Compute area-conserving redistribution from LandScan native counts and divide by target cell area upstream. Do not use a raw native count as density. Neighborhood moments exclude invalid population. CV=0 for mean<1; learned joint log-intensity/log-CV sigmoid; no monotonicity constraint. Both supports evaluated at zero-input locations.
* A4: residual enhancement, spatial/channel attention; 7×7 valid-neighbor similarity and intensity response with positive learned temperatures initialized to1 and lambda1; context-conditioned continuous mixing; Softplus head. Boundary neighbors excluded via mask. Relief and NDVI alignment/standardization are upstream data responsibilities.
* A5: L1 on supervised-valid locations. Seed42, AdamW, initial1e-4, max200 epochs, cosine eta_min1e-6, early stopping20. Stage I batch32, II batch16. Stage I frozen outputs supplied to II. Train-only normalization statistics are mandatory. Default weight decay1e-4 is used for both implementations; verify original Stage I value if exact replication is required.
* Sections3.4 / B1: reference-defined light subset, no prediction-positive filtering; separate full-domain confusion/TNLI denominators. Data validity does not mean positive brightness. DN products require an explicit distinct detection protocol and must not be mixed into physical RMSE; the generic CLI is for physical radiance products.
* A7: weak Li uses native positive-parent Q25 and ties, zero group exactly0; assign children by native-cell location, not bilinear intensity or assumed exact4:1 counts. Stratification is a documented external mask preparation step in this compact release.
* B2: annual growth only when prior TNLI>0, same fixed spatial support, consecutive years. Reference-relative deviations are differences in percentage growth (pp). The percentiles/medians are summaries of the specified country population; never confuse country means with pooled Africa statistics.
* C11 requires separate retraining for target-preprocessing configurations. C13 applies processing to fixed annual layers; it does not retrain. C13 sequential upper baseline differs from independent raw-vs-upper comparisons.
* D1: fixed VNL-trained output, BM as external reference; no BM tuning/retraining/selection. Both radiometric and TNLI domains originate from BM quality and AfriNTL validity. QA codes themselves must not be averaged.
* GDP: lnGDP vs ln1pTNLI with intercept per country and product; first differences are consecutive-year log differences. Means of country R²; no causal claims.

Not bundled: data downloads/credentials, LandScan redistribution, geodesic overlap processing, original harmonization/RNTL desaturation source, trained weights, production GeoTIFF stitching, official ADM0/ADM2 files, ISS registration/PCA, exact SNID consensus construction, urban threshold changepoint selection, third-party model implementations and exhaustive ablation runners. These require original assets or additional specified implementations. No placeholders returning paper performance values are used.

For tiled deployment, provide valid halos larger than the entire model receptive field, blend/discard halos, and check seams. The current predict CLI emits prepared tensor predictions rather than promising a validated continental GeoTIFF inference pipeline.
